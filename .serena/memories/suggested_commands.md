- Analyze: `rtk flutter analyze`.
- Full tests: `rtk flutter test`.
- Focused test: `rtk flutter test test/name_test.dart`.
- Regenerate localization: `rtk flutter gen-l10n`.
- Constraint icon assets: `rtk xvfb-run -a flutter test integration_test/constraint_icons_test.dart -d linux`.
- Solver/descriptors: `dart run bin/solve.dart`, `dart run bin/describe_puzzle.dart`, `dart run bin/query_corpus.dart`.
- Run from the project root. Shell commands use the `rtk` prefix per AGENTS.md.
