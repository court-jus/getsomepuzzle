# Get Some Puzzles

Dans ce jeu, votre but est de colorer les cases d'une grille en noir ou blanc.

Pour savoir de quelle couleur chaque case doit être coloriée, vous devez suivre certaines contraintes (leurs règles sont expliquées plus bas).

Pour colorer les cases, cliquez dessus (ou touchez-les sur mobile). Le clic fait défiler la couleur : libre → noir → blanc → libre. Sur ordinateur, le clic droit fait défiler dans l'autre sens (libre → blanc → noir → libre) ; sur mobile, l'appui long fait la même chose. Le glisser-déplacer remplit plusieurs cases d'un coup avec la couleur du cycle.

Certains puzzles utilisent une troisième couleur, le violet, et des pastilles colorées sous les cases libres montrent quelles couleurs sont encore possibles. Sur ces puzzles, le cycle inclut le violet : clic = libre → noir → blanc → violet → libre, et clic droit (ou appui long) = libre → violet → blanc → noir → libre — un seul clic droit suffit donc pour atteindre le violet.

Certaines cases sont déjà remplies et vous ne pouvez pas les modifier. Elles sont indiquées par une bordure plus épaisse.

Il n'y aura pas d'indication si vous faites une erreur mais une fois la grille complète, votre solution sera vérifiée. En cas de victoire, un autre puzzle sera automatiquement sélectionné. En cas d'erreur, la contrainte correspondante sera mise en évidence et vous pourrez modifier votre solution.

Si vous êtes bloqué, plusieurs boutons sont à votre disposition en haut de l'écran : **Indice** (icône en forme d'ampoule, voir la section Astuces ci-dessous), **Aide du puzzle** (icône point d'interrogation, qui rappelle les règles utilisées par le puzzle en cours), **Annuler** (revient sur votre dernier coup), **Redémarrer** (remet la grille à son état initial, après confirmation) et **Pause**. En mode validation manuelle, un bouton **Valider** sur fond vert apparaît également quand la grille est complète. Sur les puzzles à trois couleurs, un bouton **pinceau** change l'effet d'un toucher : en mode « retirer une option », toucher une case vide élimine une de ses couleurs au lieu de la colorer.

Pendant que vous jouez, votre temps est enregistré (voir la section Stats ci-dessous). Le jeu peut être mis en pause si besoin.

Il y a environ 88000 puzzles fournis avec l'application. Ceux que vous avez déjà résolu n'apparaîtront plus. Vous pouvez voir votre progression sous le puzzle.

Depuis le menu principal (icône en haut à gauche), quand un puzzle est en cours, vous pouvez aussi choisir **Puzzle suivant** pour passer au prochain, **Enregistrer la progression** pour mettre le puzzle de côté dans une playlist dédiée et le reprendre plus tard, ou **Partager le puzzle** pour l'envoyer à quelqu'un.

## Apprentissage

À votre premier lancement du jeu, un message de bienvenue explique le but du jeu, puis une séquence d'apprentissage présente les contraintes une par une. Chaque nouvelle règle apparaît dans une petite fenêtre d'explication la première fois que vous la rencontrez, et le jeu vous propose ensuite des puzzles centrés sur cette règle jusqu'à ce que vous en ayez joué suffisamment (5 puzzles par règle) pour passer à la suivante. Vous pouvez ignorer la séquence à tout moment avec le bouton "Ignorer l'apprentissage" dans la fenêtre d'explication, ou la redémarrer depuis le début dans la page Paramètres.

Les fenêtres du jeu apparaissent dans cet ordre : "Bienvenue" à la toute première installation, puis les nouveautés de la version ("Nouveautés") à votre premier lancement après une mise à jour, avant l'explication de toute règle que vous n'avez pas encore rencontrée. Si vous quittez le jeu pendant la présentation d'une règle, les premiers puzzles proposés au redémarrage la contiennent encore.

La page **Apprentissage**, accessible depuis le menu principal, section **Progression**, liste toutes les contraintes avec leur icône, la date à laquelle vous les avez rencontrées pour la première fois et le nombre de puzzles joués avec cette règle. Le bouton "Me rafraîchir la mémoire" à côté de chaque règle lance une courte playlist de puzzles centrés sur cette règle — pratique pour revoir une contrainte que vous n'avez pas vue depuis un moment. Il reste désactivé pour les règles que vous n'avez pas encore rencontrées.

Pendant que la séquence est en cours, la page Ouvrir rappelle que ses filtres suivent votre parcours d'apprentissage, avec un bouton de réinitialisation pour revenir aux filtres recommandés si vous les avez modifiés.

## La page Ouvrir

La page Ouvrir est l'endroit où vous choisissez quoi jouer. En haut, le menu *Collection* liste les niveaux de difficulté (Facile → Fou), suivis de vos puzzles personnels et des playlists que vous avez créées. À côté, le bouton `+` crée une nouvelle playlist, le bouton fichier importe des puzzles depuis un fichier, et l'icône corbeille supprime la playlist en cours si elle vous appartient.

L'option *Mélanger* propose les puzzles dans un ordre aléatoire. Le nombre affiché au-dessus du bouton Jouer indique combien de puzzles correspondent aux filtres actifs.

Pendant l'apprentissage, un bandeau au-dessus des filtres rappelle qu'ils suivent votre parcours d'apprentissage ; le bouton de réinitialisation du bandeau rétablit les filtres recommandés si vous les avez modifiés.

Les filtres avancés permettent d'affiner la liste :

- *Scénario* : des puzzles par style de déduction — Classique, Forme, Boîte englobante, Chemin, Symétrie, Démineur, Nonogramme, Local ou Groupe.
- *Dimensions* : largeur et hauteur minimales et maximales.
- *Seulement* : les puzzles que vous avez joués, passés, aimés ou moins aimés (PL, SK, LI, DI).
- *Nombre de couleurs* : un curseur de "Seulement 2 couleurs" à "Seulement 3 couleurs" ; les positions intermédiaires proposent les deux types de puzzles, pondérés selon la proportion choisie.
- *Règles désirées* : les types de contraintes que vous voulez voir, listés par leur code (NC, GS, IM…).
- *Taux de remplissage* : à quel point la grille de départ est remplie.

Un petit bouton de réinitialisation à côté de chaque filtre rétablit sa valeur par défaut, et le champ en bas accepte la représentation d'un puzzle collée pour l'ouvrir directement.

## Puzzles personnalisés

### Générer des puzzles

Ouvrez le menu et appuyez sur "Générer" pour fabriquer de nouveaux puzzles à la volée. Choisissez les dimensions de la grille, les types de contraintes à inclure ou exclure (listés par leur code — NC, GS, IM…), un temps maximal par puzzle, et le nombre de puzzles à fabriquer. Choisissez la playlist de destination, puis appuyez sur "Générer" — la barre de progression montre combien ont déjà été faits. La génération tourne en arrière-plan ; vous pouvez l'arrêter à tout moment et garder ce qui a déjà été produit.

### Créer des puzzles

Ouvrez le menu et appuyez sur "Créer" pour concevoir votre propre puzzle. Choisissez les dimensions et les couleurs utilisées (2 ou 3), puis appuyez sur "Commencer l'édition" pour entrer dans l'éditeur. Touchez une case pour ouvrir un menu qui permet de fixer sa valeur (noir, blanc ou violet), ou d'attacher une contrainte centrée sur cette case ; la contrainte ajoutée apparaît, et il suffit de la toucher pour la supprimer. Un bouton "Nouveau puzzle" dans la barre du haut efface tout pour repartir de zéro.

L'application tente de résoudre le puzzle au fur et à mesure de vos modifications. Les cases à bordure verte se trouvent par raisonnement direct, celles à bordure orange par élimination. La barre du haut indique le nombre de contraintes du puzzle. "Valider" lance le solveur et indique si le puzzle se résout par déduction seule, "Tester" vous laisse jouer le puzzle pour vérifier qu'il fonctionne, et "Enregistrer" le sauvegarde dans la playlist choisie.

### Playlists

Les puzzles générés et créés sont sauvegardés dans des playlists. La playlist par défaut est "Mes puzzles", mais vous pouvez en créer de nouvelles depuis la page Ouvrir. Vous pouvez aussi importer des puzzles depuis un fichier, et supprimer une playlist qui vous appartient depuis la même page.

## Astuces

Si vous êtes bloqué, le bouton d'astuce vous donne un coup de pouce progressif — chaque appui révèle un peu plus d'information. Dans le menu paramètres, vous pouvez choisir le type d'aide.

Le premier appui est le même quel que soit le mode :

- Si vous avez fait une erreur, il met en évidence la contrainte violée, ou la cellule fausse quand aucune contrainte ne le détecte directement.
- Si tout ce que vous avez rempli jusqu'ici est correct, il vous le confirme.

Les appuis suivants dépendent du mode choisi.

### Cellule déductible

Le mode par défaut. Après le diagnostic d'erreurs, les appuis suivants vous guident vers une déduction précise :

- Deuxième appui : met en évidence une case que vous pouvez déduire.
- Troisième appui : met aussi en évidence la contrainte qui justifie la déduction, avec une flèche reliant les deux. Quand la déduction fait intervenir plusieurs contraintes ensemble, elles sont toutes mises en évidence.
- Quatrième appui : applique la déduction à votre place.

Pratique quand vous voulez un petit indice sans tout vous gâcher : arrêtez-vous au deuxième appui si vous préférez trouver la justification par vous-même.

Sur un puzzle à trois couleurs, une déduction est parfois « cette couleur est impossible ici » plutôt que « cette case est noire » : l'astuce indique alors qu'une option peut être retirée, et l'appliquer fait disparaître la pastille correspondante en laissant la case libre.

### Ajout de contrainte

Au lieu de désigner une case, le deuxième appui ajoute une nouvelle contrainte au puzzle. Cette règle est cohérente avec la solution et vous donne une information supplémentaire pour avancer — le puzzle devient plus simple sans qu'on vous dise quelle case remplir. Quand plusieurs règles conviendraient, le jeu propose celle qui débloque le plus de cases d'un coup.

Après l'ajout d'une contrainte, le cycle reprend au diagnostic d'erreurs sur l'appui suivant.

Pendant l'apprentissage, le jeu ne propose jamais une règle que vous n'avez pas encore rencontrée.

## Raccourcis clavier

Sur ordinateur, ces touches pilotent un puzzle pendant que vous jouez :

- **U** — annuler le dernier coup
- **R** — recommencer le puzzle (avec confirmation)
- **P** — mettre en pause ou reprendre
- **H** — afficher une astuce
- **N** — passer au puzzle suivant
- **Entrée** — valider (quand la validation manuelle est active)
- **Échap** — ouvrir le menu
- **Espace** — sur les puzzles à 3 couleurs, basculer entre poser une couleur et retirer une option

## Paramètres

La page Paramètres règle la façon dont le jeu vérifie votre travail, vous aide, et stocke vos données.

**Langue** : choisissez la langue d'affichage (Anglais, Français ou Espagnol).

**Thème** : choisir entre Clair, Sombre ou Beige, ou suivre le réglage système (par défaut).

**Validation** : choisissez si la grille est vérifiée manuellement (vous appuyez sur un bouton) ou automatiquement (dès qu'elle est entièrement remplie).

**Noter les puzzles** : si l'écran de notation apparaît entre les puzzles pour que vous puissiez exprimer votre appréciation sur une échelle à cinq niveaux (de très négatif à très positif).

**Délai avant puzzle suivant** : combien de temps le jeu attend avant d'afficher le puzzle suivant (1, 3 ou 10 secondes), ou Manuel pour attendre que vous passiez au suivant.

**Erreurs** : comment les erreurs sont signalées pendant que vous jouez — Temps réel (toutes les cases fausses), Décompte (un nombre d'erreurs) ou Attendre (seulement quand la grille est complète).

**Astuces** : comment le bouton astuce vous aide — en pointant une case déductible ("Cellule déductible") ou en ajoutant une nouvelle contrainte qui simplifie le puzzle ("Ajout de contrainte"). Voir la section Astuces ci-dessus pour les détails.

**Griser les contraintes complètes** : si une contrainte satisfaite s'estompe au fil de la partie. Désactivez cette option pour les garder bien visibles.

**Pause automatique en cas d'inactivité** : si aucune interaction n'a lieu pendant le délai choisi (ou si l'application perd le focus), le chronomètre se met en pause pour ne pas continuer à tourner pendant votre absence.

**Mon niveau** (0-100) : oriente les puzzles qui vous sont proposés vers votre vitesse de raisonnement. Plus c'est élevé, plus c'est difficile.

**Adaptation automatique** : quand activé, votre niveau s'ajuste tout seul à partir de vos temps de résolution. Désactivez-le pour régler le niveau à la main.

**Rejouer l'onboarding** : redémarre la séquence d'apprentissage depuis le début — utile pour revoir les fenêtres de présentation des règles. Vos statistiques de jeu sont conservées.

**Effacer toutes les statistiques** : efface tout l'historique de jeu — temps, notes, statuts joué/passé. L'action est irréversible et demande une confirmation.

**Dossier de synchronisation** : pointez l'application vers un dossier que vous synchronisez entre vos appareils pour qu'ils partagent le même historique de jeu — voir le guide des stats multi-appareil ci-dessous. Non disponible sur la version web.

## Stats

Le jeu enregistre le temps passé sur un puzzle, le nombre d'astuces utilisées et le nombre d'erreurs. Chaque partie est conservée : rejouer un puzzle ajoute une entrée au lieu d'écraser la première. Ces données restent sur votre appareil — rien n'est collecté automatiquement. Si vous résolvez beaucoup de puzzles, je serai ravi que vous me les envoyiez : je m'en sers pour calculer la difficulté des puzzles.

La page Stats est accessible depuis le menu principal, section **Progression**. Les cartes du haut indiquent combien de puzzles vous avez joués et terminés, votre durée moyenne, votre usage des astuces et votre appréciation ; viennent ensuite les répartitions par collection, par contrainte et par complexité, vos appréciations, et les dernières parties avec leur date, leur durée et leur nombre d'astuces.

Le bouton **Partager** (ou **Ouvrir** sur ordinateur) exporte les stats pour me les envoyer, et le bouton **Importer** permet de réinjecter un fichier de stats précédemment exporté.

Vous pouvez aussi synchroniser vos stats entre différents appareils en pointant l'application vers un dossier partagé et en utilisant un outil de synchronisation comme Syncthing ou Dropbox — voir le [guide des stats multi-appareil](https://leveque.cc/getsomepuzzle/doc/fr/crossplay.html) pour les instructions.
